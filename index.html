1. Arquitetura de Sistemas Computacionais

1.1. Qual a diferença entre o modelo Centralizado e o Distribuído?

No modelo Centralizado (mainframes), todo o processamento ocorre em um único servidor central acessado por terminais. Já no modelo Distribuído (Cliente-Servidor), as tarefas são divididas: o cliente cuida da interface e o servidor processa a lógica de negócio e banco de dados.

1.2. Cite duas outras arquiteturas de sistemas e suas funções:

  • Peer-to-Peer (P2P): Todos os nós agem como cliente e servidor simultaneamente (ex: BitTorrent).
  • CDN (Content Delivery Network): Servidores geograficamente distribuídos para acelerar a entrega de conteúdo estático.

2. Infraestrutura Web e Hospedagem

2.1. Como funciona a analogia do Domínio, IP e DNS?

O IP é a coordenada geográfica do servidor, o Domínio é o endereço memorável (ex: site.com) e o DNS funciona como o GPS que converte o domínio no IP correto.

2.2. Quais são os principais tipos de hospedagem?

  1. Compartilhada: Vários sites dividem recursos no mesmo servidor.
  2. VPS: Servidor fatiado em máquinas virtuais dedicadas.
  3. Dedicada: Um servidor físico exclusivo para o cliente.
  4. Nuvem (Cloud): Recursos distribuídos e escaláveis sob demanda.

3. O Protocolo HTTP

3.1. Quais são os métodos HTTP fundamentais?

  • GET: Consulta/solicita dados.
  • POST: Envia dados para criar um novo recurso.
  • PUT/PATCH: Atualizam recursos existentes.
  • DELETE: Remove um recurso do servidor.

4. APIs, DevTools e Git

4.1. O que é JSON e qual sua importância?

O JSON (JavaScript Object Notation) é o formato padrão chave/valor usado no consumo de APIs para troca leve de dados entre cliente e servidor.


                    {"tema": "Arquitetura Web",
                     "status": 200,
                     "autor": "Isabelle Cristine Kanzler"}

4.2. Qual a diferença entre Git e GitHub?

O Git é a ferramenta de controle de versão instalada localmente na máquina. O GitHub é a plataforma na nuvem para hospedar e compartilhar repositórios Git.

5. Estilização com CSS

5.1. O que é CSS e qual é o seu papel na Web?

O CSS (Cascading Style Sheets) é a linguagem responsável pelo visual, layout e design das páginas web. Enquanto o HTML define a estrutura dos elementos, o CSS controla a apresentação (cores, fontes, espaçamentos e responsividade).

5.2. Como funciona a regra da Cascata e a Especificidade?

A Cascata determina que, quando há regras conflitantes, a última declarada no arquivo costuma prevalecer. A Especificidade é o peso de cada seletor: seletores por ID têm maior peso que por Classe, que por sua vez superam seletores por Tag/Elemento.

5.3. O que é o Box Model: Padding vs. Margin?

No CSS, todo elemento HTML é tratado como uma caixa composta por camadas:

  • Content: O conteúdo real (texto, imagem, etc.).
  • Padding (Espaçamento Interno): É o espaço dentro do elemento, entre o conteúdo e a sua borda. Exemplo: padding: 20px; em um botão impede que o texto fique colado nas bordas.
  • Border: A linha da borda que envolve o elemento.
  • Margin (Espaçamento Externo): É o espaço fora do elemento, criado em volta da sua borda para afastar esse elemento de outros vizinhos na tela. Exemplo: margin: auto; em uma imagem centraliza a caixa afastando os lados igualmente.

Sintaxe de relógio (Sentido Horário):

  • margin: 10px 20px 15px 5px; → Topo (10px), Direita (20px), Baixo (15px), Esquerda (5px).
  • margin: 15px 10px; → Vertical (15px topo/baixo), Horizontal (10px lados).

5.4. Elementos e Pseudo-elementos (::) no CSS

Um elemento HTML é a tag da estrutura (<h1>, <p>, <a>, <div>). No CSS, o Seletor de Tag aplica a regra a todas as tags daquele tipo (ex: p { color: red; } deixa todos os parágrafos vermelhos).

Os Pseudo-elementos (::) permitem estilizar partes virtuais ou internas de um elemento que não possuem uma tag própria no HTML:

  • ::first-letter → Altera apenas a primeira letra de um texto.
  • ::first-line → Altera a primeira linha inteira do parágrafo.
  • ::before e ::after → Inserem conteúdo decorativo antes ou depois do elemento (ex: colocar um ícone de "+" ao final de um link).

5.5. Pseudo-classes (:) no CSS

As Pseudo-classes (:) servem para alterar o estilo visual de um elemento de acordo com o seu estado ou com a interação do usuário:

  • :hover → Aplica o estilo quando o usuário passa o ponteiro do mouse por cima do elemento (ex: mudar a cor ou remover o sublinhado de um link).
  • :focus → Aplica o estilo quando o elemento recebe foco (ex: quando o usuário clica dentro de uma caixa de texto <input> para digitar).
  • :active → Aplica o estilo no exato momento em que o elemento é clicado.

5.6. Principais técnicas de Layout: Flexbox e Grid

  • Flexbox (1D): Ideal para alinhar itens em uma única direção (linha ou coluna). Perfeito para menus de navegação, centralizar elementos e listas.
  • CSS Grid (2D): Ideal para estruturas bidimensionais (linhas e colunas simultaneamente). Perfeito para criar a estrutura geral da página e layouts complexos.
